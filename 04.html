ARQUIVO 04 / O PADRÃO

Você já tem quatro letras.

Agora uma pista para descobrir como elas devem ser lidas:

“Não olhe para o que está escrito.
Olhe para onde cada coisa começa.”

As quatro respostas da etapa anterior começam com:

D   O   L   A

Mas isso ainda não é a mensagem.

Troque cada letra pela próxima letra do alfabeto.
